Context (grounded 2026-06-16 web search — sources in the conductor message):
- Auto-posting is a MATURE category. UNIFIED posting APIs exist (Ayrshare, Post-for-me, Blotato, posteverywhere) — build on ONE of these rather than integrating 8 platforms. Platforms treat auto-posts identically to manual (no algorithm penalty).
- THE GATE is app-review/approval per platform (Meta/Instagram/Facebook/Threads free but App-Review gated; TikTok sandbox audit; LinkedIn MDP partner approval; YouTube quota units). Some costs: X ~$0.20/post-with-URL; Reddit ~$12k/yr commercial (SKIP); Bluesky/Pinterest free rate-capped. Instagram Basic Display deprecated Dec 2024 — use the Graph/Content Publishing APIs (often business/creator accounts only).
- FUSION: the operator ALREADY built the content-PREP half — the post-intake pipeline (muddytires.ca/post), social-seo-playbook (per-platform keyword/hook rules), the EDITOR-LADDER (proof-zoom / rebuilt-hook / management-plane), the vanlife-editor missions. THIS mission adds: community/auth front-end + the connect-and-distribute back-end. They are two halves of one product.
- This answers the MONETIZATION question (resilience-2 strawman #5): FREE spots map + community; PAID "post to all your socials" creator tier (the niche social scheduler for vanlifers). Niche-vertical social tools are a proven SaaS.

STRAWMAN STAGES (operator confirms):
1. Accounts/auth + community profiles on Cloudflare (D1 users, Workers auth or Cloudflare Access).
2. Connect-socials: OAuth per platform via a UNIFIED API (Ayrshare-class) → store tokens encrypted (Workers secrets / encrypted D1). Start with the free/easy platforms (Bluesky, Pinterest, YouTube), add Meta/TikTok as their app-reviews clear.
3. Distribute: the editor pipeline's output (caption + reel + thumbnail per platform) → scheduled post via the unified API. Reuse social-seo-playbook for per-platform shaping.
4. Community: shared spots feed, creator profiles, follow/connect (the "couples connect their socials" social graph).

HONEST RISKS: app-review timelines (weeks, Meta/TikTok); secure social-token storage (security-sensitive); per-platform format quirks (partly solved by the playbook); this is a real SaaS product, sequenced AFTER the map is solid on Cloudflare. Don't bundle into resilience-2 — this is the phase on top of it.

Amanah: the operator's biggest-leverage idea — the community + the social engine are what turn muddytires from a utility into a destination. Scope it fully before building; receipts per stage (a real post lands on a real connected account).
